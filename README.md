A token launch radar: it reads a sealed DefiLlama snapshot, ranks pre-token protocols by an implied value derived from TVL, seven-day growth and time running without a token, and gives each one a concrete farm plan. The dashboard is a static page with a sortable, filterable board and a detail view per protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
